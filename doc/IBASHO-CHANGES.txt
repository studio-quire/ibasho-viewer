Ibasho: changes to Linden Lab's files

Ibasho is a modified version of the Second Life viewer source code (Linden Research, Inc.;
secondlife/viewer, develop at 81bc977d693e36feb3e468a84ea55cdcbbb37f70), distributed under the GNU LGPL 2.1
(doc/LGPL-license.txt). As section 2(a) asks, this lists every file of the original that Ibasho
changed, with the dates of the changes (UTC). Each changed source file also says so in its header,
and the changed lines are marked "Ibasho". Files Ibasho added (indra/newview/ibasho*) carry their own
LGPL headers.
